# 房间模板 · 双击就能跑

这是「小鲸鱼房间」的最小版，去掉了一切依赖，只留一个 `index.html` + 一张底图。

## 怎么跑

1. 双击 `index.html`（Chrome / Edge 都行，不需要装任何东西、不需要起服务器）
2. 应当看到：一张等距房间图，下面的按钮可以切时段、切天气
3. 鼠标移到床 / 桌子 / 书架，会浮出名字；点一下弹出小抽屉

## 换成你自己的房间

1. 准备一张 **3:2** 的等距图（建议 1536×1024），命名成 `sample-room.png` 覆盖掉原来的
2. 刷新页面 —— 图就换好了
3. 点「标注模式」，把三个热区拖到床、桌子、书架上（拖框移动），再点一次退出
   - 位置会存在浏览器里（`localStorage`），刷新还在

要做成会保存到服务器，就把最后一步换成 `POST /api/room/hotspots`（见攻略第 3 节 A）。

## 里面有什么

| 部分 | 位置 | 说明 |
|---|---|---|
| 页面骨架 | `index.html` 前半段 | SVG 容器 + 控制条 |
| 时间与天气 | `index.html` 的 `periods` / `weathers` | 4 时段 × 3 天气，线性插值 |
| 天色渲染 | `paint()` | 只改 CSS 变量 `--brightness / --ambient / --sun` |
| 热区 | `DEFAULT_SLOTS` | `rect:[x,y,w,h]`，viewBox 坐标 |
| 热区内容 | `CONTENT` | 真实项目里改成 `fetch('/api/room/inspect')` |
| 标注模式 | `enableDrag()` | 拖动热区 + 存 localStorage |

## 已知的简化

- 示例底图是静态 PNG，窗外的云不会动；真实版窗外是独立一层，可以单独换
- 天气粒子是简单位移，不是物理下落；够用，也更省电
- 没有人物姿态；要加就看攻略第 3 节 C
